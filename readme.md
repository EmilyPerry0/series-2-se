# Usage Instructions (Frontend)
To start the visualization, run this in your terminal from the root of the project.

`streamlit run frontend/Home.py`

The visualization will appear in your browser.
# Usage Instructions (Backend)
import `main.rsc` and run `main()` in a Rascal terminal.

# Textual Output
Each project (smallSQL, HSQLdb, and benchmarkProject) has two textual output files: one for its type 1 clone classes, and one for its type 2 clone classes.
Additionally, there is one file named allStatistics.txt. This file contains the textual output of statistics, metrics, and clone examples for all 3 projects. This is the output you see in the console when running the code.
All of these files are in the folder TextualOutput
